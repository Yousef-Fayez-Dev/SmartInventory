# SmartInventory

A practice project built with **C# and Entity Framework Core** to apply and demonstrate core EF Core concepts through a simple inventory management system.

## Technologies

* C#
* .NET 9
* Entity Framework Core 9
* SQL Server
* LINQ

## EF Core Concepts Applied

* Entity Relationships
* Data Annotations & Fluent API
* Migrations
* Change Tracking
* Validation
* Delete Behaviors
* Eager Loading
* Explicit Loading
* Lazy Loading
* LINQ Queries
* Projection
* Aggregation
* Navigation Properties
* Transactions & Savepoints

## Project Structure

* `Entities` — Database entities and relationships
* `Migrations` — EF Core database migrations
* `Program.cs` — EF Core demonstrations and examples
* `AppDbContext` — Database context and configuration

## Configuration

Before running the project:

1. Create an `appsettings.json` file in the project directory.
2. Add your SQL Server connection string.
3. Use `appsettings.example.json` as a template.

The actual `appsettings.json` is excluded from Git using `.gitignore`.

## Purpose

This project was created as a hands-on practice project after completing an Entity Framework Core learning stage.

It focuses on understanding how EF Core works in practice rather than building a production-ready application.
